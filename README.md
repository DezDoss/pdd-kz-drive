# Автодром ПДД РК

Тренажёр практического экзамена на водительские права категории B в Казахстане.
Сейчас этот экзамен сдают только на автоматизированном автодроме.
Штрафные баллы здесь начисляются по контрольным таблицам приложения 5 к Правилам приёма экзаменов
(приказ МВД РК № 862, ред. на 27.07.2026). Если набрано 100 баллов и больше, экзамен не сдан.

**Играть: https://dezdoss.github.io/pdd-kz-drive/**

Игра работает в браузере на компьютере (клавиатура) и на телефоне (руль и педали на экране).
Её можно поставить как приложение, после первого открытия она работает без интернета:
- iPhone: Safari → «Поделиться» → «На экран „Домой“»;
- Android: Chrome → меню → «Установить приложение».

Это неофициальный учебный тренажёр. К МВД и центрам приёма экзаменов он отношения не имеет.
Теорию можно повторить в [карточках ПДД РК](https://dezdoss.github.io/pdd-kz-cards/).

## Упражнения

Всего на экзамене 10 упражнений, в тренажёре пока 6. Номера — по п. 66 Правил.

| № | Упражнение | Что проверяется (баллы) |
|---|---|---|
| 1 | Старт | ремень (5), левый указатель на линии «Старт» (5) и его выключение в пределах 10 м (5), тронуться за 20 с (25) / 30 с (100) |
| 2 | Крутой подъём и спуск | задний габарит за линией фиксации, передний — до «Стоп» (25); стоять 3 с (25); тронуться за 30 с (25); откат больше 0,2 м (20) |
| 6 | Параллельная парковка задним ходом | правые колёса на линии фиксации (20), контрольные линии (20), 2 минуты (15) |
| 3 | Пешеходный переход | не заезжать на «зебру» при остановке (25), стоять 3 с (25), тронуться за 30 с (25) |
| 7 | Регулируемый перекрёсток | «Стоп» на запрещающий сигнал (100), на разрешающий дольше 20 с (20) / 30 с (100), указатель поворота (5) |
| 10 | Финиш | правый указатель до линии «Финиш» (5) |
| — | Общие (КТ11) | общее время (100), пропуск упражнения (100), столкновение или наезд (100), скорость выше 20 км/ч — 5 за каждые 5 с |

Полная таблица КТ1–КТ11, включая упражнения 4, 5, 8 и 9, и нормативы зон собраны в [docs/pravila-862.md](docs/pravila-862.md).

Некоторых величин в Правилах нет, их задал сам тренажёр:
- размер кармана для парковки — 7,0 × 2,6 м;
- лимит времени автодрома — 10 минут;
- уклон эстакады — 12 % (Правила допускают 8–16 %).

На настоящем автодроме нет пешехода и машины на поперечной улице. Здесь они добавлены для практики ПДД, а их нарушения идут в протокол отдельно, без баллов.

## Разработка

```sh
npm test            # автопилот проходит маршрут: чистый заезд — 0 баллов, каждая ошибка — свой штраф
node build.mjs      # сборка
./deploy.sh         # тесты, сборка, push в main, dist/ — в ветку gh-pages
python3 -m http.server 8791 --directory dist    # открыть сборку локально: http://localhost:8791
```

Сборка без зависимостей: модули из `src/` склеиваются в один скрипт внутри `app.html`. На выходе получаются:
- `dist/` — PWA для GitHub Pages: манифест, service worker, three.js и шрифты лежат рядом;
- `index.html` — та же страница без `<head>`, для встраивания как артефакт claude.ai (three.js и шрифты грузятся с CDN);
- `dist/debug.html` — игра плюс автопилот из тестов (`window.__autopilot`) для проверки отрисовки. На хостинг не выкладывается.

| Файл | Что внутри |
|---|---|
| `src/geom.js` | геометрия на плоскости, проверка пересечений, генератор случайных чисел |
| `src/course.js` | разметка автодрома и нормативы зон |
| `src/rules.js` | штрафные баллы КТ1–КТ11 и замечания по ПДД |
| `src/car.js` | машина с АКПП: кинематическая модель, уклон, «ползучесть», стояночный тормоз |
| `src/actors.js` | светофор, пешеход, машина на поперечной улице |
| `src/exam.js` | упражнения, общие требования, подсказки |
| `src/sim.js` | шаг мира целиком |
| `src/view.js` | графика на Three.js r128, вся процедурная |
| `src/ui.js`, `src/main.js` | приборная панель, клавиатура и сенсор, меню, протокол |
| `pwa/` | манифест, service worker, иконки, three.js, шрифты |
| `test/` | автопилот и тесты: логика не зависит от отрисовки |
